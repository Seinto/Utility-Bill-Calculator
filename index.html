Googleスプレッドシート連携の手順

  1. Googleドライブで新しい「Googleスプレッドシート」を作成します。
  2. メニューの [拡張機能] > [Apps Script] を開きます。
  3. 表示されたエディタの内容を全て消去し、以下のスクリプトを貼り付けて保存します： 
    function doGet() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet();
  var data = {};
  ['electric', 'gas', 'water'].forEach(function(name) {
    var s = sheet.getSheetByName(name);
    if (!s) { data[name] = []; return; }
    var vals = s.getDataRange().getValues();
    if (vals.length <= 1) { data[name] = []; return; }
    var head = vals[0];
    data[name] = vals.slice(1).map(function(row) {
      var obj = {};
      head.forEach(function(h, i) { obj[h] = row[i]; });
      return obj;
    });
  });
  return ContentService.createTextOutput(JSON.stringify({ok:true, data:data}))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var param = JSON.parse(e.postData.contents);
  var sheet = SpreadsheetApp.getActiveSpreadsheet();
  ['electric', 'gas', 'water'].forEach(function(name) {
    var s = sheet.getSheetByName(name) || sheet.insertSheet(name);
    s.clear();
    var list = param[name] || [];
    if (list.length === 0) return;
    var keys = Object.keys(list[0]);
    s.appendRow(keys);
    list.forEach(function(item) {
      s.appendRow(keys.map(function(k) { return item[k]; }));
    });
  });
  return ContentService.createTextOutput(JSON.stringify({ok:true}))
    .setMimeType(ContentService.MimeType.JSON);
}
  4. 右上の [デプロイ] > [新しいデプロイ] をクリックします。
  5. 種類の選択で [ウェブアプリ] を選択します。
  6. 設定を以下のように変更します：
    • アクセスできるユーザー: 「全員 (Anyone)」
  7. [デプロイ] を押し、発行された 「ウェブアプリ URL」 をコピーします。
  8. アプリの「設定」タブ内の Web App URL 欄に貼り付けて「URLを保存」を押してください。
データはこの端末のブラウザ内（localStorage）に保存されるほか、「設定」タブでGoogleスプレッドシートのWeb App URLを登録すると、そのスプレッドシートにも自動保存されます。
計算方法：電気・水道は「合計メータ − 56Bメータ = 56Aメータ」を求め、検針差分（使用量）の比率で当月料金を按分します。ガスは専用メータが無いため、同月の電気使用量比で按分します。水道は奇数月(1・3・5・7・9・11月)のみ検針し、隔月分の使用量・料金を対象期間の各月に均等按分して連月で集計します。
